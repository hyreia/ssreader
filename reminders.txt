X --nomerge: creates all lines, doesn't make a combined version (merge)
X --mergeonly: don't create the lines, just merge the existing files in alphanumerical order
X --section: skips all sections that don't have the given name (can be used with nomerge and mergeonly)

--read "text to read" -o output filename

Supported inline directives:

<voice VOICE>
    Changes the Kokoro voice for subsequent sentences.

<speed NUMBER>
    Changes the speech speed for subsequent sentences.

<pause NUMBER>
    Inserts NUMBER seconds of silence before the next sentence.
<break> 
    Insert a four second pause of silence before the next sentence.

<reset>
    resets voice and speed back to defaults

Directives are only recognized at the beginning of a sentence.
Multiple directives may appear consecutively.
The first non-directive text ends the directive region.
Directive state persists until changed.
